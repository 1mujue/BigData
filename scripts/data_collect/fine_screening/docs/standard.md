# 论文复现选题精筛标准

精筛从方向粗筛得到的候选中，结合论文主要内容、公开材料和复现条件，评价其复现适合程度，形成候选名单和选择依据。通用标准说明如何判断；本批次要求说明研究范围、资源条件和偏好。阅读者同时使用两者。

## 选题阶段的判断深度

先读清论文的主要贡献和结论，再判断有没有值得尝试的验证路径。改进方法、实证分析和负面发现均可作为复现目标。论文有多个研究问题时，可以选择其中重要的主要结论，不要求覆盖所有实验；选择应有实质意义，避免仅因方便而选择边角消融或孤立示例。

如果某个问题的不同答案会改变去留或优先级，就在精筛时查清。只影响入选后如何配置和执行的问题，留到任务设计阶段。例如，新增训练、不可获得的数据、必要的模型访问能力可能影响选择；最终型号、样本数、提示词、版本、解码参数、运行预算和验收细则通常随后确定。某个配置问题如果实际决定了能否开展工作，也需要提前查明。

可行性说明可以简短：指出主要结论、可能的检验路径以及关键依赖即可。尚未确定完整实验方案，不构成低分理由。已有的更深材料可以保留作后续参考，不把每份深入笔记的全部细节变成所有候选的必填条件。

适当减少模型、数据或轮次，本身不降低核心内容覆盖度或条件可还原性。需要判断的是这些调整是否改变结论含义、关键机制或比较条件。定性评价可以成立，前提是判断依据清楚、过程可重复。选题不以预期获得正向提升或较大效果为前提。

## 阅读与提取

预读使用完整标题、摘要和已有标签，安排精读顺序。已有证据明确表明不符合本批条件时，可以注明理由后暂缓；关键词本身不等于完整的贡献或训练需求判断。预读不给四维数值评分。

精读覆盖判断所需的主要贡献、相关方法、实验设置与结果；按具体疑点补查附录、代码、数据或模型材料。读取代码到能够判断材料覆盖和剩余工作即可，精筛不要求安装环境或试跑论文。

逐篇提取论文类型、方向、主要内容、方法、相关模型、数据集、指标、材料入口和关键资源条件。原文报告、阅读者的判断与暂定的复现设想分开说明。作者报告的数字不写成自己的复现结果。

代码发布承诺、可访问的仓库、已经检查到的实现和实际成功运行是不同状态。没有作者仓库可以依据论文形成实现路径；有仓库也要看它是否包含相关内容。不要因模型访问方式、编程语言、多智能体等标签直接推断准备工作。

重要判断附原文片段及位置。章节、表图编号、PDF 页码、代码文件与函数等均可作为定位。引用必须来自实际读取的来源；机器核对引用片段是否出现，语义支持关系由复核判断。

## 四维评价和档次

完整等级定义见随任务提供的四维评分表。阅读者只给 A、B、C、D 的等级和理由，程序计算总分和档次。

| 维度 | 核心判断 |
| --- | --- |
| A：结论可检验性 | 是否有清楚的主要结论、比较与评价依据，能否进行有意义的检验 |
| B：核心内容覆盖度 | 大致可行的验证能否承接重要主要内容，保留关键机制或对照 |
| C：实验条件可还原性 | 关键条件能否确定和取得，材料是否支持可信的可用路径 |
| D：实施适配度 | 在已有材料基础上，还需多少准备和实现工作，大致是否适合本批条件 |

C 关注实验条件，D 关注剩余工作。同一问题不机械重复扣分；如果确实产生不同影响，分别说明。分数衡量本批次的复现适合程度，不另设创新程度、效果大小、年份或熟悉数据集的加分项。

证据不足时等级为 `null`，并说明缺口。读过来源也可能无法确认某个事实；未说明、相互矛盾和尚未取得材料都需按实际情况处理。已经查明关键条件存在实质障碍，可以给低等级；缺少尚未决定的执行细节，不自动成为未知等级。

先处理本批适配条件，再处理明确的 0 分障碍、关键未知项、阅读和实现路径准备情况。已有明确不适配证据时暂缓，即使其他项目尚不清楚。其余记录中：

| 档次 | 进入条件 | 用途 |
| --- | --- | --- |
| 优先 `priority` | 四项均至少 2 分，相关正文已读，主要依据与实现路径明确 | 优先进入名单讨论 |
| 可选 `possible` | 四项已评，没有 0 分，至少一项为 1 分；同样具备正文依据和实现路径 | 保留并说明具体取舍 |
| 待补查 `needs_evidence` | 影响适配或评分的重要信息尚未建立，或相关正文、实现路径尚未明确 | 定向补查 |
| 暂缓 `defer` | 已确认不符合本批条件，或存在 0 分所代表的实质障碍 | 保留理由，暂不推荐 |

一项等级为 `null` 时总分为 `null`。四项均已给出等级时可以计算总分，但只有优先和可选的精读记录进入排序；分数不能抵消已确认的不适配条件。档内按总分降序排列，同分用论文标识保持稳定顺序。

## 复核与名单形成

阅读者逐篇判断，协调者管理整批覆盖和最终取舍。总分辅助比较，最终名单可以同时包含优先与可选论文，每篇记录选择理由。相同数据集、模型或环境可以复用；是否重复看主要研究问题和结论，不按共享工具直接淘汰。

组员抽查论文的关键原文依据。可选取入选和暂缓的案例，核对拟复现目标、所需材料以及准备工作是否与原文相符。确认的事实误读应修正对应记录。

## 与课程任务的衔接

上述信息提取和批量筛选对应课程第三阶段。入选之后，在第四阶段确定具体复现范围、实验设置、资源预算、执行要求和 judge，形成 `task.md` 与任务推导材料。评分、资料核对或命令示例本身不构成论文复现。
